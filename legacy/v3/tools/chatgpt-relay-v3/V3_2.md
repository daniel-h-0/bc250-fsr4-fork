# BC-250 Relay v3.2

v3.2 keeps protocol `BC250_RELAY_V3` and is compatible with legacy flat v3 jobs while adding session-aware operation.

## Improvements

- `fsr4`, `ps5`, and `vcn` sessions can each run one job concurrently.
- Long shell jobs no longer block GitHub polling for the other sessions.
- Jobs are idempotent: if the namespaced result already exists, the queued duplicate is consumed without re-execution.
- Dashboard and human control: Pause, Resume, Stop, Note, Priority.
- Shell timeout terminates the entire process group.
- Full stdout/stderr remain available as local artifacts while GitHub results are clipped.
- Heartbeat commits are reduced to a configurable default of 300 seconds.
- Upgrade is transactional: compile, isolated sidecar health/dashboard/session tests, production switch, health validation, automatic rollback on failure.
- A user-systemd watchdog checks production health every minute.

## Paths

Jobs: `relay-v3/jobs/<session>--<job_id>.json`

Results: `relay-v3/results/<session>--<job_id>.json`

Status: `relay-v3/status/heartbeat.json`

Dashboard: the upgrade script prints the key-bearing local URL.
